# PRD: 文章AI解读功能

## 用户故事

### US1: 选中文章文本并触发AI解读

**作为** 文章阅读者
**我希望** 选中文章中的一段文字后能看到"AI解读"浮动按钮，点击后获得AI对该段落的专业解读
**以便** 我更好地理解难懂的内容

**验收条件：**

| 编号 | 场景 | Given | When | Then |
|------|------|-------|------|------|
| AC1.1 | 正常选中文本 | 用户在文章详情页阅读文章 | 用户用鼠标选中一段文本（长度>0且≤2000字符） | 在选中区域附近显示一个浮动的"AI解读"按钮 |
| AC1.2 | 点击解读按钮 | "AI解读"按钮已显示 | 用户点击"AI解读"按钮 | 前端发送解读请求到后端，携带选中文本+文章上下文；前端展示loading动画 |
| AC1.3 | 未选中文本 | 用户在文章详情页 | 用户未选中任何文本 | 不显示"AI解读"按钮 |
| AC1.4 | 选中文本过长 | 用户在文章详情页 | 用户选中文本超过2000字符 | 截断选中文本到2000字符，显示"已自动截取前2000字"提示，仍显示"AI解读"按钮 |
| AC1.5 | 取消选中 | "AI解读"按钮已显示 | 用户点击文章其他区域或取消选中 | "AI解读"按钮消失 |
| AC1.6 | 用户未登录 | 未登录用户在文章详情页选中文本 | 用户点击"AI解读"按钮 | 弹出登录提示/跳转登录页 |
| AC1.7 | AI正在解读中 | 用户已触发一次解读 | 用户再次选中文本 | 显示"AI正在解读中，请稍候"提示，不显示新按钮，直到当前解读完成 |

### US2: AI严格基于原文解读

**作为** 产品设计者
**我希望** AI解读严格基于提供的原文内容，不编造、不脱离原文
**以便** 保证解读的准确性和可信度，建立用户信任

**验收条件：**

| 编号 | 场景 | Given | When | Then |
|------|------|-------|------|------|
| AC2.1 | 固定系统提示词 | 后端收到文章解读请求 | 后端构建AI API请求 | 系统提示词为固定内容："你是文章专属解读助手，只能基于提供的原文解释选中片段，不准脱离原文，不准编造内容，语言通俗易懂，条理清晰。" |
| AC2.2 | 提供完整上下文 | 后端收到文章解读请求 | 后端构建AI API请求 | 请求中包含：选中文本原文 + 选中文本在文章中前后各500字的上下文 + 文章标题 |
| AC2.3 | 系统提示词硬编码 | 系统部署运行 | 任何用户发起解读请求 | 系统提示词为代码中硬编码的固定值，不通过任何外部输入修改 |
| AC2.4 | 上下文超长截断 | 文章上下文超过模型token限制 | 后端构建请求 | 优先保留选中文本完整，按前后各削减1/2的规则截断上下文，直到总token数在限制内 |

### US3: 查看解读结果与异常处理

**作为** 文章阅读者
**我希望** 看到格式良好的AI解读结果，并且在失败时有清晰的提示和重试方案
**以便** 我能顺利获取解读内容

**验收条件：**

| 编号 | 场景 | Given | When | Then |
|------|------|-------|------|------|
| AC3.1 | 正常流式返回 | AI正常响应解读请求 | 后端逐字返回解读内容 | 前端以Markdown格式流式渲染展示，内容逐字出现 |
| AC3.2 | 解读完成 | 所有解读内容已返回 | AI返回流结束信号（STREAM_END） | 显示"AI解读完成"并收缩loading动画，同时显示"复制"按钮 |
| AC3.3 | 请求超时 | 解读请求发起 | 30秒内未收到完整响应 | 显示"AI响应超时，请稍后重试"提示 + 重试按钮 |
| AC3.4 | 服务错误 | 解读请求发起 | 后端返回5xx错误或网络异常 | 显示"解读失败，AI服务暂不可用"提示 + 重试按钮 |
| AC3.5 | AI返回空结果 | 解读请求发起 | AI返回空内容 | 显示"AI暂时无法解读此内容，请尝试选择其他段落"提示 |
| AC3.6 | 用户触发重试 | 解读失败后显示重试按钮 | 用户点击重试 | 重新发起解读请求，重置状态为loading |
| AC3.7 | 复制解读结果 | 解读成功完成 | 用户点击"复制"按钮 | 将解读文本复制到剪贴板，显示"已复制"toast提示 |
| AC3.8 | 关闭解读面板 | 解读面板已展示 | 用户点击关闭按钮或文章其他区域 | 解读面板关闭，不清除选中状态 |

### US4: 后端多模型支持与自动降级

**作为** 系统运维人员
**我希望** 系统能配置多个大模型提供商，自动选择可用模型提供解读服务
**以便** 确保服务的高可用性和可扩展性

**验收条件：**

| 编号 | 场景 | Given | When | Then |
|------|------|-------|------|------|
| AC4.1 | 多模型配置 | 后端YAML配置了多个模型提供商（DeepSeek/Kimi/通义千问/讯飞等） | 用户发起解读请求 | 系统按配置的优先级顺序选择第一个可用模型 |
| AC4.2 | 模型降级 | 最高优先级模型调用失败 | 用户发起解读请求 | 系统自动切换到下一个优先级模型重试 |
| AC4.3 | 所有模型不可用 | 所有已配置模型均调用失败 | 用户发起解读请求 | 返回明确的服务不可用错误（503） |
| AC4.4 | 新增模型提供商 | 运维人员在YAML中添加新模型配置 | 系统重新加载配置 | 新模型自动加入可用模型池，无需修改代码重启 |
| AC4.5 | 模型健康检查 | 某模型多次返回错误 | 系统后台检查 | 该模型被临时标记为不可用（冷却5分钟），自动跳过 |

### US5: 解读结果展示面板

**作为** 文章阅读者
**我希望** 解读结果在文章页面侧边或浮层中展示，不影响我继续阅读原文
**以便** 我可以边看原文边对照解读

**验收条件：**

| 编号 | 场景 | Given | When | Then |
|------|------|-------|------|------|
| AC5.1 | 展示位置 | 解读请求已触发 | 前端展示解读结果 | 结果以右侧滑动面板或浮动弹窗展示，不遮挡文章主体内容 |
| AC5.2 | 移动端适配 | 用户使用移动设备 | 解读面板展示 | 解读面板自适应为底部抽屉式（drawer），不遮挡过多屏幕空间 |
| AC5.3 | 重新选择 | 解读面板已展示 | 用户选中新的文本段落 | 检测到新选中内容，按钮再次出现，可发起新解读覆盖当前结果 |

## 接口契约速览

| 方法 | 路径 | 描述 | 请求体 | 响应体 |
|------|------|------|--------|--------|
| POST | `/article/api/ai/interpret` | 文章解读（流式） | `InterpretReq` | SSE流 |
| GET | `/article/api/ai/models` | 获取可用模型列表 | - | `List<ModelInfoVO>` |

### InterpretReq
```json
{
  "articleId": 123,
  "selectedText": "选中的文本内容",
  "startPos": 100,
  "endPos": 200
}
```

### SSE响应格式
```
data: {"type":"STREAM","content":"解读文本片段..."}
data: {"type":"STREAM","content":"继续..."}
data: {"type":"STREAM_END","content":"完整解读文本"}
data: {"type":"ERROR","message":"错误信息"}
```

## 非功能需求

| 类别 | 需求 | 目标值 | 说明 |
|------|------|--------|------|
| 性能 | API首字响应时间 | P95 < 3秒 | 从请求到第一个token返回 |
| 性能 | 完整响应时间 | P95 < 5秒 | 从请求到流结束 |
| 可靠性 | 解读成功率 | > 99% | 含自动降级后的成功率 |
| 并发 | 并发解读请求 | >= 50/秒 | 正常业务峰值 |
| 限流 | 用户日调用限制 | 50次/天 | 防止API费用失控 |
| 超时 | 单次请求超时 | 30秒 | 含模型降级重试时间 |
| 可用性 | 模型可用率 | > 99.5% | 至少1个模型在线 |
| 兼容性 | 浏览器兼容 | Chrome/Firefox/Safari/Edge 最新2版本 | 含移动端响应式 |

## 边界条件汇总

| 边界条件 | 触发条件 | 预期行为 |
|----------|----------|----------|
| 选中文本为空 | `selectedText` 为空或仅含空白字符 | 不显示AI解读按钮 |
| 选中文本超长 | `selectedText` > 2000字符 | 前端截断到2000字符+提示 |
| 上下文超长 | 上下文+选中文本+prompt > 模型token限制 | 后端截断上下文（优先保留选中文本） |
| 用户未登录 | 未登录用户点击解读 | 跳转登录页 |
| 解读进行中 | 用户再次选中文本 | 提示"AI正在解读中" |
| 模型全部不可用 | 所有配置的模型调用失败 | 返回503 + 错误提示 |
| 网络中断 | SSE流传输中断 | 显示已接收内容 + "连接中断"提示 |
| 限流触发 | 用户当天解读次数>50 | 返回429 + "今日解读次数已用完" |
| 特殊字符 | 选中文本含HTML标签/特殊字符 | 正确转义处理 |
| 空白文章页 | articleId对应的文章无内容 | 返回400 + "文章内容为空" |
